## 📌 Descripción del Proyecto
El objetivo principal de este sitio web es presentar de forma visual, limpia y estructurada mi perfil personal y académico, mis habilidades técnicas principales, los proyectos que he realizado y un formulario de contacto.

El proyecto está construido desde cero aplicando buenas prácticas de maquetación semántica, diseño accesible, responsivo y una paleta visual profesional y armoniosa.

---

## 🛠️ Tecnologías Utilizadas
* **HTML5:** Estructuración semántica utilizando etiquetas como `<header>`, `<nav>`, `<main>`, `<section>`, `<article>` y `<footer>`.
* **CSS3:**
  * Uso de variables CSS (`:root`) para la gestión centralizada de colores y estilos.
  * Maquetación flexible mediante `display: flex`.
  * Interactividad y animaciones con la pseudoclase `:hover` y transiciones suaves.
  * Tipografía e integración con Google Fonts (*Plus Jakarta Sans*).
